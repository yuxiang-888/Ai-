# 淘宝女装剪辑 Agent 规则升级验收

## 源码审计

现有入口：桌面快捷方式 → 本地统一网站（FastAPI，8080）→ `/api/agent/jobs` → EditingAgent → 本地 ASR、MediaPipe、规划器、FFmpeg、OpenCV 质检。SQLite 保存任务与 Agent 记录；旧引擎仍供兼容接口使用。本次不迁移数据库、不删除素材、不改变登录和公网隧道。

原测试基线8项通过。发现尺码时长硬限制、商品细节不强制面料证据、逐阶段贪心选择挤占背面时长、Y参数未经校准却位移500像素、冻结画面仅警告等问题。

## 本次变更

- 联合比较尺码、面料、背面候选组合，保留完整ASR分段边界；每类最多64个候选，有限搜索。
- 均码识别、冗余与重复话术降权；尺码片段可超过8秒。必要信息或可行组合缺失时停止。
- 渲染前检查真实首秒全身/正面/稳定性证据、ASR分段切断、尺码和面料、口播中显式颜色覆盖。语音颜色覆盖不等于视觉颜色展示已经验证。
- 时间轴带ASR句子索引和原片时间区间；证据检查失败保留候选计划。
- Y=500保留待校准元数据，默认实际位移改为0，不纵向拉伸。
- 同景别普通手势变化不视作整帧闪现；疑似长冻结、整帧严重过曝、解码帧数不足阻止自动合格。
- 网页后台规则版本同步至运行时。

## 验证

22项测试通过；保留2项既有FastAPI生命周期弃用警告。

真实素材VID67Q056：原片60.311秒，候选24.267秒，1080×1440，H.264/AAC。复用ASR与姿态缓存，总流程14.006秒，其中渲染8.034秒；不能代表首次识别耗时。检测727帧，黑帧0、整帧闪现0、整帧严重过曝0，最长疑似近冻结48帧。最终NEEDS_REVIEW；不是人工验收合格成片。

## 尚未完成的验收

- ASR仍有错词；完整ASR分段不保证自然语言完整句意。
- 姿态转身代理指标仍需人工标注校准；回原位、保护动作边界、人物消失与跨景别异常尚未形成完整可靠硬门。
- 首帧主图导出、全部颜色视觉覆盖、音画同步实测仍待完善。
- 冻结阈值可能误报静止讲解，需要人工样本校准。
- 自动修正目前仅支持有限时长修正和渲染回退，不宣称具备任意画面缺陷的自动替换能力。
- 仅1条真实素材，尚未完成20条人工标注评测、首次运行性能及批量验收。
- 现有套装和大货的最小时长策略尚需松绑；候选搜索上限可能遗漏有效组合，应报告待复核而非断言素材无可用片段。

下一步需要各品类原片与人工合格成片/正确切点，以及剪映Y参数截图或工程，校准识别和画面参数。
