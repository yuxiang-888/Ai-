# 主机集中运行

负责人和客户通过同一个公网网址连接主机。生产数据库、模型、任务执行、原片、成片保留在主机；负责人无需在第二台电脑安装服务或复制数据库。

负责人使用各自的账号登录。在负责人后台将成员授权为负责人后，对方刷新即可管理同一份账号数据、知识库和任务。撤销权限或停用账号在下一次请求时生效。普通注册不赋予管理员权限。

账号后台空闲时每15秒读取主机数据，切回页面或网络恢复时刷新；搜索、弹窗和操作期间避免刷新打断。手动刷新按钮始终可用。API不缓存账号和任务响应。

公网通道启动成功后同步更新桌面Agent、负责人后台和公网入口地址。临时域名可能变化，已发送到其他电脑的旧网址无法自动更新，需要重新发送；固定域名尚未配置。

负责人便携包作为迁移和备份保留，不能同时把其中的独立数据库当作第二个生产主机。主机断电、休眠、断网或隧道停止时远程访问不可用。

验收使用两个独立浏览器会话验证账号列表一致、授予权限后无需重新登录、撤销/停用立即拒绝访问。此测试不代表客户素材隔离已完成，现有素材库及任务列表仍为共享工作区；独立客户私有数据空间需要进一步实现所有权检查。
